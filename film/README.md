# دفتر الماء | The Water Notebook

فيلم قصير (5 دقائق و5 ثوانٍ) بالذكاء الاصطناعي عن استنزاف المياه الجوفية في حوض صنعاء والفيضانات المفاجئة، وكيف يمكن للمجتمع استعادة المياه بإحياء السدود والمدرجات القديمة.

## المتطلبات المُلتزَم بها
- فيلم واحد بقصة متكاملة، مدته بين 5 و7 دقائق.
- تنسيق أفقي 16:9 بدقة 1920×1080، بصيغة MP4 (H.264 + AAC).
- السرد بالعربية مع **ترجمة إنجليزية مدمجة في الصورة** وملف SRT منفصل.

## الملفات
- `script.md` — القصة والسرد والترجمة لكل مشهد.
- `assets/` — صور المشاهد (مولّدة بالذكاء الاصطناعي).
- `audio/` — السرد الصوتي لكل مشهد (مولّد بالذكاء الاصطناعي).
- `subtitles-en.srt` — الترجمة الإنجليزية بالتوقيت.
- `build_film.py` — سكربت التجميع (حركة كاميرا بطيئة، انتقالات، ترجمة، موسيقى خلفية).
- `output/the-water-notebook.mp4` — الفيلم النهائي (غير مُدرج في Git بسبب حجمه، يُعاد توليده بالسكربت).

## إعادة البناء
```bash
python3 -m venv .venv-film && .venv-film/bin/pip install pillow numpy imageio-ffmpeg
.venv-film/bin/python film/build_film.py
```
